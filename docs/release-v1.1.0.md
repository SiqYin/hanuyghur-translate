# 汉维辞典 v1.1.0

拉丁维文全面修正版：改用 **2008 年 1 月新疆维吾尔自治区民族语言文字工作委员会鉴定验收的官方拉丁维文（ULY）方案**，全库转写重算并与老维文一一对应；界面新增拉丁维文版本；维-汉互译支持拉丁输入。另含全新圆形徽标。

- 在线：https://siqyin.github.io/hanuyghur-translate/
- 三端下载：本页下方 Assets

## 这一版改了什么

**拉丁维文改用 2008 官方方案（修正 v1.0.0 的转写问题）**

v1.0.0 的拉丁维文混用了三个来源（词库源数据自带列、例句管线、运行时引擎），拼写年代不一，与老维文原文对不上。本版统一为单一引擎、官方规则：

- `ئې/ې` → **ë**（2008 年修订：由旧案的 é 改为 ë）
- `ژ` → **zh**、`ج` → **j**（2008 年起固定，消除旧案 j/zh 二义）
- 词中 hamza 一律转写为隔音符号 `'`：`مۇئەللىم → mu'ellim`、`سۈنئىي → sün'iy`、`قائىدە → qa'ide`
- 相邻字母会被误读成二合字母时加 `'`：`تاللانغان → tallan'ghan`、`ئىنگلىزچە → in'glizche`（无歧义不加：`shinjang`、`sheher`）
- 阿拉伯标点/数字转西式（`؛ → ;`）

**全库重算，转写与原文一一对应**

词库 532,192 义项、维汉词条 371,766 条、例句 41,747 句的拉丁维文全部用同一引擎重算。双向回环测试 139 例（含官方《世界人权宣言》第一条样句）全部通过：老维文 → 拉丁 → 老维文、拉丁 → 老维文 → 拉丁 均可复原。

**例句重筛**

例句拉丁维文句首大写（`Bu mesile ikkinchi derijilik.`）；剔除 170 句 AI 产生的坏句（混入拉丁/西里尔字母的混合文字句）。

**界面新增拉丁维文标准版本**

界面第四语言 **Uyghurchë**：全部界面文案按官方 ULY 拼写（Xenzuche-Uyghurche Lughet / Lughet / Terjime…），自左向右排版，与老维文界面并存。

**维-汉互译支持拉丁维文**

翻译页维-汉方向：直接输入拉丁维文（`U tünügün manga bir qëtim tëlëfon qildi.`）即可翻译成汉文——输入先经引擎转为老维文再送翻译网关。查词同样支持 ë 拼写（`tëlëfon`）。汉译维输出仍为老维文 + 拉丁维文双行，句首大写。

**圆形徽标**

README 与网页端图标改为圆形（黑→蓝渐变 + 白色梅花），与汉南辞典统一；Windows / Android 应用图标保持原样。

## 安装

| 平台 | 文件 | 说明 |
|---|---|---|
| Windows | `HanUyghurDict-1.1.0-win-x64.zip` | 解压后运行 `HanUyghurDict.exe`；未签名，SmartScreen 会提示“更多信息 → 仍要运行” |
| Android | `HanUyghurDict-1.1.0-android.apk` | 直接安装，需 Android 6.0+；debug 签名，安装时需允许“未知来源” |
| 网页 | `HanUyghurDict-1.1.0-web.zip` | 解压后用任意静态服务器打开 `index.html`，或直接访问在线版 |
