# 汉维辞典 v1.1.1

自动更新检测、繁体中文界面、维译汉简繁输出，并继续例句放量。

- 在线：https://siqyin.github.io/hanuyghur-translate/
- 三端下载：本页下方 Assets

## 这一版改了什么

**自动检测更新**

进入应用时自动查询 GitHub 最新版本：无更新时什么都不显示；有更新时按当前界面语言弹出提示（已有更新版本 v{x}，是否前往更新？），左侧「暂不」关闭弹窗，右侧「更新」直达 GitHub Release 最新版。网页端打开新标签，Windows / Android 转系统浏览器。网络不可用时静默。

**选项记忆**

查词 / 翻译页、翻译方向、简繁选择、维文显示模式、界面语言全部记住——下次进入应用直接回到上次离开时的界面与选项。

**繁体中文界面**

界面新增第五语言「繁中」（繁體中文），与简中、English、老维文、拉丁维文并列，共五语言、键位完全对齐。

**维译汉区分简繁输出**

翻译页维-汉方向新增「简体 / 繁体」输出切换（汉译维方向不需要，中文简繁均可直接输入）。实现方式与汉南辞典一致：由翻译模型按选择输出对应用字。实测：`U tünügün manga bir qëtim tëlëfon qildi.` → 繁体「他昨天給我打了一次電話。」

**例句放量（进行中）**

继续用免费 Index-Translate 网关翻译汉文例句：v1.1.0 发布时 41,577 条，本次发布已增至 50,144 条，向 12 万条目标推进（管线支持断点续跑，后续版本继续收录）。

## 安装

| 平台 | 文件 | 说明 |
|---|---|---|
| Windows | `HanUyghurDict-1.1.1-win-x64.zip` | 解压后运行 `HanUyghurDict.exe`；未签名，SmartScreen 会提示“更多信息 → 仍要运行” |
| Android | `HanUyghurDict-1.1.1-android.apk` | 直接安装，需 Android 6.0+；debug 签名，安装时需允许“未知来源” |
| 网页 | `HanUyghurDict-1.1.1-web.zip` | 解压后用任意静态服务器打开 `index.html`，或直接访问在线版 |

## 已知问题

- 例句为 AI 翻译，未经母语审校；老维文个别词存在写法变体（归一化会自动统一）。
- 词库底座 Anatilim 无明确许可证，`NOTICE.md` 按个人学习/研究定位。
- Windows 包未签名、APK 为 debug 签名。
- 词形还原只给 top-1，歧义词没有备选。
