# 汉维辞典 v1.0.0

汉文 ⇄ 维吾尔语双向词典的首个正式版。网页、Windows、Android 三端同源，离线可用。

- 在线：https://siqyin.github.io/hanuyghur-translate/
- 三端下载：本页下方 Assets

## 这一版有什么

**双文字，不是两套数据**

全库拉丁维文（ULY）由老维文（UEY）按 2009 标准正字法派生：hamza 载体、`ch/sh/gh/ng/zh` 最长匹配、`ك/ي` 归一化、ZWNJ 处理。界面、例句、AI 译文共用同一套规则，两种文字不会不同步。93 条回环用例全部通过。

**点词即对照**

词条、例句、AI 译文里的每个维文词都能点：老维文点开是拉丁维文，拉丁点开是老维文，同时给出词典对应词条与复制按钮。

**屈折词回到原形**

维吾尔语是粘着语。点 `ئىچىمەن` 会显示原形 `ئىچمەك`、词尾 `-ى` `-مەن` 和汉文释义「喝」；`قەلىمى → قەلەم` 走的是元音弱化还原。

**三语界面**

简体中文 / ئۇيغۇرچە / English，默认简中。维语界面下顶栏、标签、提示整体右起，词条内容仍按各自书写方向渲染。

**AI 翻译**

汉-维 / 维-汉双向，可换任意 OpenAI 兼容端点（接口设置只保存在本机）。默认网关是公共接口，忙时会超时，建议自备端点。

## 安装

| 平台 | 文件 | 说明 |
|---|---|---|
| Windows | `HanUyghurDict-1.0.0-win-x64.zip` | 解压后运行 `HanUyghurDict.exe`；未签名，SmartScreen 会提示“更多信息 → 仍要运行” |
| Android | `HanUyghurDict-1.0.0-android.apk` | 直接安装，需 Android 6.0+；debug 签名，安装时需允许“未知来源” |
| 网页 | `HanUyghurDict-1.0.0-web.zip` | 解压后用任意静态服务器打开 `index.html`，或直接访问在线版 |

## 已知问题

1. **例句 41,747 条，未到 12 万目标。** 生成管线已跑通（`tools/translate_examples.py`，32 句/批），但上游 API 额度用尽（402），暂停放量；补齐额度后可断点续跑。
2. 例句维文为 AI 翻译，尚未经母语审校；作为学习参考可以，作为规范用例请谨慎。
3. 默认 AI 网关是公共接口，高峰期限流或 504；请在「接口设置」里换成自己的端点。
4. 维语界面做了顶栏与文字方向适配，长词条页面仍有细节可打磨。
5. 词形还原目前给 top-1，歧义词（如 `ئىتى` 狗/马）暂不展示备选。
